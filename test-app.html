安装指南

方法一：直接使用（推荐）

  1. 将整个music文件夹复制到车机存储设备
  2. 使用车机浏览器打开 index.html
  3. 将页面添加到主屏幕

方法二：APK安装

  1. 安装 Node.js 和 Cordova CLI
  2. 运行 build-apk.bat 脚本
  3. 安装生成的APK文件

方法三：在线构建

  1. 上传项目到 PhoneGap Build
  2. 使用 config.xml 构建APK
  3. 下载并安装APK

系统要求

  • Android版本: 5.0+ (API 21+)
  • 浏览器: Chrome 60+, Firefox 55+
  • 屏幕: 建议7-12寸横屏
  • 网络: 需要互联网连接播放在线音乐

使用说明

基本操作

  • 播放/暂停: 点击中央播放按钮
  • 切换歌曲: 点击上一首/下一首按钮
  • 调节音量: 点击音量滑块
  • 查看播放列表: 点击播放列表按钮

键盘快捷键

  • 空格键: 播放/暂停
  • 左右箭头: 切换歌曲
  • 上下箭头: 调节音量
  • L键: 显示播放列表
